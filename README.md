# IESE Energy Club — Website

Source for the IESE Energy Club website. The site is a single, self-contained page (`index.html`) — all styles and scripts are inline, no build step or dependencies required.

## Editing the site

- **Quick edits in the browser:** open `index.html` here on GitHub and click the pencil (✏️) icon to edit, then commit.
- **Preview locally:** download `index.html` and double-click it to open in any browser.
- **Bigger changes:** clone the repo, edit `index.html`, and push.

## Structure

Everything lives in `index.html`:

- Nav + hero
- Stats band
- Who we are / What we do
- Events (Global Energy Day)
- Join / Why join
- Footer with social links

## Contributing

VPs and officers have write access. For small copy or link fixes, edit directly on `main`. For anything larger, open a branch and a pull request so it can be reviewed before it goes live.
